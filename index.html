01
Motivation · 동기

한 장의 사진을 문장으로

기계가 사진을 설명하려면 세 가지를 동시에 풀어야 한다 — 보고, 쓰고, 정렬한다.

이미지 캡셔닝은 시각 표현 추출, 문장 생성, 그리고 단어마다 이미지의 어느 부분을 볼지 정렬하는 문제를 한 모델 안에 모두 담는 가장 단순한 과제다.

  • See — 픽셀을 공간 정보를 가진 시각 특징으로 변환한다.
  • Write — 문법적으로 올바른 문장을 한 단어씩 생성한다.
  • Align — 각 단어 시점마다 주목할 이미지 영역을 결정한다.
  • 오늘날의 멀티모달 LLM(GPT-4V, Gemini Vision 등)도 본질은 같은 골격이다.
02
Method · 방법

CNN 인코더 + 소프트 어텐션 LSTM 디코더

동결된 ResNet-101이 이미지를 49개 영역 벡터로 만들고, LSTM 디코더가 어텐션으로 영역을 골라 단어를 생성한다.
  • 인코더 — ImageNet 사전학습 ResNet-101(동결), 출력 7×7×2048 = 49개 영역 벡터. 한 번만 계산해 디스크에 캐싱.
  • 소프트 어텐션 — 매 시점 49개 영역에 가중치 α를 부여해 문맥 벡터를 합성. 게이트 β로 기능어 시점에는 영상을 무시.
  • 디코더 — LSTMCell(2560→512) + Linear 출력 헤드로 다음 단어 분포를 생성.
  • 이중 확률 정규화 — 모든 영역이 골고루 주목받도록 강제해 어텐션 붕괴를 방지.
03
Setup · 실험 설정

Flickr8k · 학습은 디코더만

인코더는 동결하고 어텐션, 디코더, 단어 임베딩만 학습한다. 추론에는 빔 서치를 사용한다.
  • 데이터 — Flickr8k 8,091장, 이미지당 약 5개 캡션. 60/20/20 학습/검증/평가 분할(시드 42).
  • 어휘 — 최소 등장 5회, 2,248단어 + 특수토큰 4개. 최대 길이 22.
  • 최적화 — Adam lr 4e-4, 배치 32, 최대 30 에폭, 검증 손실 5에폭 조기종료.
  • 장비 — Apple Silicon MPS, PyTorch 2.12, 총 약 27분 학습.

05
Interpretability · 어텐션 시각화

명사 단어에서 올바른 객체에 주목

단어를 생성하는 매 시점의 어텐션 히트맵 — 명사 토큰에서 해당 객체 영역이 또렷하게 밝아진다 (대표 샘플).
평가 이미지에 대한 토큰별 어텐션 오버레이 — 각 타일은 같은 224×224 이미지에 해당 생성 단어의 어텐션 질량을 칠한 것.
06
Conclusion · 결론

작은 데이터로 재현한 멀티모달의 원형

동결된 비전 타워 + 작은 언어 헤드 + 어텐션 브리지 — 현대 멀티모달 LLM과 같은 골격을 노트북 한 대로 끝까지 돌렸다.
  • 어텐션 맵은 해석 가능하다 — 이중 확률 정규화가 사주는 "내부 증거".
  • 빔 서치는 이 규모에서 사실상 공짜로 약 +2 BLEU-4를 얻는다.
  • 주요 실패 = 언어 사전(prior) 우세 + 동결 인코더의 한계.
  • 다음 단계 = Transformer 디코더 + 크로스 어텐션으로의 자연스러운 확장.
